# 练习页参考图实现

> 此文记录历史原型。当前全前端与侧栏实现、运行及验证说明见 [frontend-redesign.md](frontend-redesign.md)。活动界面已统一，原型组件和山景样式不再作为入口使用。

以用户提供的参考图为视觉基准：暖白纸面、深墨绿控件、大字号 Source Serif 4 正文、珊瑚橙录音动作、低对比度渐隐山景。

## 入口与实现

- 有稿件时默认进入新版练习页；`?practice=prototype` 继续可用。
- 顶部“稿件管理”进入 `?practice=legacy`，保留新建、删除和整篇管理功能。没有稿件时使用现有新建流程。
- `src/PracticePrototype.tsx` 组织目录、正文、音频工作区、录音入口和录音反馈；复用 App 的业务回调。
- `src/practice-tokens.css` 集中管理颜色、间距、圆角、字体、边框、阴影、动效及山景路径。
- `src/practice-prototype.css` 管理练习页布局及交互状态；`src/practice-feedback.css` 保留真实反馈的详细呈现。
- 山景自托管，来源与许可见 `THIRD_PARTY_NOTICES.md`。替换 `public/images/practice-mountains.jpg` 或 token `--pa-landscape` 即可。

## 状态与语义

- 录音进度按已经存在录音的句子计数，切句不自动视为完成。
- 波形由实际音频解码生成，显示音量包络，不代表发音质量。两轨沿用统一秒数刻度。
- Space 开始或停止录音；输入框、按钮、下拉框、链接、展开控件和模态框中的键盘操作不触发全局快捷键。
- 录音或保存时锁定切句、稿件切换和相关音频设置。保留暂停、循环、倍速、下载、删除、历史、编辑、分句和合并。
- 录音前只显示空状态；录音后提供回放、识别与评测操作；有真实评测结果后显示评分和依据。
- 无可靠时间信息的反馈不提供片段回放。评测失败保留录音及恢复操作。
- 支持 hover、active、selected、disabled、recording、playing、保存/任务状态、已录音状态和 reduced-motion。

## 视觉检查与验证

截图目录：`docs/evidence/practice-prototype/`。检查 1440×900、1366×900、1050×900，以及 760 和 390 宽度。常规桌面视口内同时显示当前句、示范音频、录音入口和我的录音标题；超长正文正常展开，必要时允许滚动。

- `npm run build`：TypeScript 与生产构建。
- `npm run test:ui`：真实本地后端、示范生成与播放、浏览器测试麦克风录音、保存及历史、键盘停止录音、默认入口、旧版稿件管理、反馈片段回放、失败恢复与模型设置。
- 发音反馈使用明确标注的离线 fixture 验证呈现与定位；未据此声称远程评分服务已实测。麦克风使用浏览器测试设备，未验证具体硬件。
