# Speech Practice 0.2.2 使用说明

本包是 Windows x64 测试版，包含新版前端和可收起侧栏。推荐使用 Windows 11 x64；其他系统版本尚未验证。

## 安装与开始

1. 运行 `Speech Practice Setup 0.2.2.exe`，选择安装目录。无需自行安装 Python 或 Node.js。
2. 启动 Speech Practice，在“设置”中下载 Kokoro 示范语音模型和 Whisper small.en 识别模型。安装包不含模型权重，首次下载需要网络和足够磁盘空间。
3. 在“稿件”中新建英文稿件，进入练习，选句、生成示范、听示范，然后开始录音。首次录音需允许麦克风访问。
4. 停止录音后可以回放，检查转写差异，或重新录音。“分析”查看当前录音反馈，“总结”整理当前稿件已有结果。
5. 点击侧栏顶部按钮收起或展开导航；偏好会记住。Tab 移动焦点，Enter 或空格操作按钮。

模型下载完成后，默认示范和本地识别可在本机运行。识别差异不是发音评分。云识别或评测需要自行配置凭据，可能产生供应商费用，上传前有确认；本次交付未验证收费服务。

## 数据、升级和卸载

默认数据与模型位于 `%LOCALAPPDATA%\speech-practice`，设置中的文件存储区域可以查看或调整目录。升级前请退出软件，并备份实际数据目录。新版本沿用原数据格式；卸载器不会主动删除练习数据。删除稿件等应用操作仍会按界面提示影响相应数据。

## 故障反馈

下载失败可检查网络后在设置中重试；麦克风不可用时检查 Windows 麦克风权限和输入设备。启动失败或其他错误，请提供版本、Windows 版本、操作步骤和错误截图；不要附带云服务密钥或未经确认的私人录音。

## 校验

在 PowerShell 中执行 `Get-FileHash -Algorithm SHA256 '.\Speech Practice Setup 0.2.2.exe'`，将结果与校验文件对照。校验只能确认文件一致性，不能替代可信来源和代码签名。
