# 0.2.2 Windows 测试版交付记录

本版应用版本为 0.2.2，后端协议与健康接口版本仍为 0.2.1；接口和数据格式未改变。

## 变化

- 统一稿件、练习、分析、总结和设置界面，使用本地字体与植物素材。
- 练习页提供完整稿件、当前句操作和共享音频播放控制。
- 侧栏支持键盘收起、展开、明确选中标记和偏好记忆。
- 源码归档增加 public 素材，排除测试证据和录音；交付包只收录选定截图。

## 构建

执行 `scripts/build_backend.ps1` 重新冻结 CPU 后端，然后 `npm.cmd run package` 构建 TypeScript/Vite 和 NSIS x64 安装程序。应用无需用户安装 Python / Node.js；模型另行下载。

应用源码重建需要 Windows、Node.js/npm 和 uv。运行 `build.bat`，或依次执行上面两条构建命令。精确依赖见 package-lock.json、uv.lock。源码包不含依赖环境、原生依赖完整对应源码或模型权重。

## 验证范围

冻结后端在 PATH 排除 Python/Node、禁止外部 HTTP 代理连接的情况下完成真实 Kokoro 生成、Whisper CPU 转写、WAV 下载、上传、整篇导出与 Range 请求。ASR 输入使用生成的示范音频，不代表真人录音准确率。云评测仅验证未配置状态与历史存储，未调用收费服务。

界面回归检查播放、测试麦克风、选句、编辑拆合、错误恢复、历史、分析定位、设置、双语和响应式布局。先前并行重建 dist 导致一次页面 404；生产文件稳定后重新运行整套检查。

桌面验证使用隔离数据目录，通过 Electron IPC 连接真实冻结后端，检查稿件显示和侧栏，并捕获程序运行截图。详细结果见交付包中的 JSON 记录。

最终生产构建通过；整套界面回归 11 项通过（56.7 秒）。NSIS 安装到项目隔离中文目录，退出码 0。安装程序与应用 Authenticode 状态为 NotSigned。安装后的程序进一步检查真实示范播放和虚拟麦克风保存；它不是硬件麦克风质量测试。
