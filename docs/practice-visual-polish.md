# Oracy：Practice 视觉迭代

## 当前轮：纯色竖线音频、定位光与数据反馈

用户最新明确要求覆盖此前波形渐变方向：中部音频使用独立竖线，颜色不采用渐变。

- 主播放器及展开音轨移除 SVG 渐变和渐变引用。已播放竖线统一纯蓝，未播放区域为浅灰；主播放器线宽为 1.5px，使用 non-scaling-stroke 保持竖线间的空气感。波形仍来自真实 PCM 峰值；合成测试音频呈现规则包络，不代表真实语音波形。
- 中部播放按钮也改为纯蓝；保留细珊瑚色指针和基于 audio.currentTime 的进度。没有用装饰动画伪造波形或播放进度。
- 当前句使用蓝紫径向定位光和两条细竖线标记，使当前练习位置易于识别。播放时仅背景光轻微呼吸，系统及应用减少动画设置会关闭该动画，停止播放后光恢复静态。录音时切换为珊瑚色。中央工作区保留低对比空间光，音频保持纯色。
- 发音反馈展示最多四个词的真实评分条；缺失评分明确标记。语速使用 WPM 数字与 0–300+ 的刻度，仅表示测量值，不给出未经依据的快慢判定。停顿使用录音时间轴标记实际返回的估计区间，保留 ≥0.7 秒、依赖 ASR 时间戳、需回听复核的说明。
- 图形只在有数据时显示；无数据时保留简短状态。停顿过滤负值、非有限数、越界及低于阈值的区间，不把图形当作声学静音检测或发音评分。

相关代码：`CoachEvidence.tsx`、`CoachPanel.tsx`、`Waveform.tsx`、`PracticeAudio.tsx`、`workspace.css`。既有 native-workspace 回归增加词级缺失评分、WPM 值、停顿区间位置与越界过滤、波形无渐变断言。视觉 fixture 的 126 WPM、2–3 秒间隔、词级评分均为离线 UI 测试数据。

验证：生产构建、完整 Playwright 19/19 和开发 Electron 检查通过；最后补齐阈值过滤及应用减少动画规则后，相关回归 6/6 再次通过。已核对专注页与播放器截图，未重新打包安装程序。

## 第二轮：阅读尺度、轻量反馈和参考音频配色

根据后续评审与用户明确提出的波形配色要求继续细化，保留三栏和全部业务入口。

- 当前句最大字号从 35px 降至 29px、字重降至 400、行高调整为 1.8；高亮进一步降低不透明度。上下文降至 21–25px，中央表面改为接近中性的 `#fcfcfd`，两侧保留轻微冷色。
- Coach 调整为紧凑反馈行：40px 图标、13px 建议、更弱的边界；无数据项使用透明表面和中性状态文字，但有录音时仍可打开分析。没有估计停顿数据时只说明所需时间戳，不给出假定存在问题的建议。
- 播放器降低外框不透明度、边界及投影，缩减内部高度。播放键保持唯一强操作。
- 个人录音不再使用从紫色起始的大跨度渐变。主播放器和展开的示范/录音轨道共用 `WaveGradient`：电蓝 `#1674ff` → 青蓝 `#20a9e8` → 蓝 `#357afa` → 蓝紫 `#6479ef`，采用 SVG `spreadMethod="reflect"` 重复短渐变带。颜色固定在时间轴上，不做无依据的循环变色动画。
- 主波形峰值高度从 19 降为 16、线宽改为 1.8，让真实波形更细。未播放区域为浅灰 `#c9d1de`；播放指针为 1px 珊瑚色。没有改写真实峰值的相对关系，也没有生成装饰波形替代音频。

## 2026-10-04：基于对比评审的组件细化

本轮按用户新提供的对比图和评审继续打磨，保持既有三栏和业务流程。以下内容为当前实现；后面的迭代记录属于历史。

- 移除正文滚动区的背景、边框与阴影，保留独立的播放器表面。工具栏次级操作弱化为无边框按钮，功能与可访问名称保持不变。
- 英文朗读文字使用随应用打包的 Source Sans 3；专注模式限制阅读行宽，区分当前句和上下文，使用换行连续的柔和高亮。录音时继续显示珊瑚色状态。
- 专注模式增加句子位置节点，长稿件最多显示 24 个位置采样点；保留有无障碍名称的原生 progress。这表示当前句位置，不表示练习已完成。
- 波形继续从音频解码产生 180 个真实峰值，已播放区域采用 SVG 渐变，未播放区域保留冷灰色。每个实例使用唯一渐变 ID。播放时通过 requestAnimationFrame 读取 audio.currentTime，暂停或卸载后取消更新，不模拟音频进度。
- 播放键使用蓝色渐变、柔和投影和悬浮/按压响应；沿用系统减少动画和应用动画设置。侧栏采用透明渐变表面与较轻的选中背景。
- 反馈卡片分别使用紫、蓝、橙及中性色。概览呈现问题证据，发音卡片呈现评测返回的操作建议；保留评分、来源限制、缺失数据和旧版本录音提示，不生成没有依据的纠音建议。

## 实机迭代

1. 基线：中央过宽、Coach 偏窄、标题和句间距偏大，播放器辅助操作视觉重量过高。
2. 第一轮：限制工作空间宽度，校准三栏、字号、阅读宽度和图标比例。保存 `round-1-*` 与 `compare-1-*`。
3. 第二轮：使用接近参考图的窗口内部尺寸 1468×854；细分 surface 与控件灰阶，采用接近参考图长度的测试稿件，重新检查阅读密度。保存 `round-2-*` 与 `compare-2-*`。
4. 第三轮：收紧 Coach、播放器，精修渐变评分环、播放键、徽标和语义图标；根据实机截图修正竖线波形的 SVG 渐变坐标。保存 `round-3-*` 与 `compare-3-*`。
5. 最后校准：根据补充要求加入低透明度环境色、弱化 Coach 外框、改用随文本换行的 Focus 高亮、可滑动选中指示层、轻微句子切换与按压响应。保存 `final-*` 与 `compare-final-*`。

对比图左边是裁去壁纸后的参考窗口，右边是实际运行截图；后续轮次按相同窗口比例比较。参考截图中的 Notes、播放列表和无实现依据的综合评分没有作为装饰控件复制。

## 设计约束

- 最大工作空间 1468px；展开侧栏 272px，收起 64px；Coach 400px；1468px 窗口下中央 796px，阅读面板 756px。窄屏继续使用图标导航和辅助抽屉。
- 环境色承担空间材质；鲜明色集中在品牌标记、当前句、主播放键、波形和语义反馈。Coach 采用开放分组，减少独立卡片外框。
- Focus 高亮随文字换行，保持自然阅读宽度；上下文使用不同透明度。分段控件共享可移动指示层；动画 180–220ms，沿用减少动画和关闭动画设置。
- 波形从真实音频解码，按相对峰值适配可视高度；示范使用蓝色，个人录音使用紫蓝色，实时录音使用珊瑚色。未播放段继续保留冷灰层级。颜色不是评测结论。
- 次级循环与整篇播放放入播放器的省略号菜单；保留无障碍名称、键盘焦点和原有操作行为。
