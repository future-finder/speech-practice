# ELOVERIS · 软件品牌适配交付
版本：2026-10-05 / River Identity 1.0

以最后认可的蓝白河流稿为基准。本包取代早期圆环、方孔及轨道探索稿。

1. 阅读 docs/BRAND_SYSTEM.md，理解品牌与产品的连接。
2. 把 docs/CODEX_ADAPTATION_PROMPT.md 与本目录一起交给项目中的 Codex。
3. 用 assets/svg 的母版替换品牌显示素材，按需使用 PNG 与 Windows ICO。
4. 导入 styles 中的令牌与可选动效类；依据现有架构绑定真实状态。
5. 对照 docs/INTEGRATION_CHECKLIST.md 验收。reference/interaction-preview.html 可直接用浏览器打开。

资产：10 个 SVG，含蓝色、深蓝、黑色、反白符号及组合字标；多尺寸透明 PNG；蓝底反白应用图标；多尺寸 Windows ICO。组合字标为路径，运行时无需安装字体。字体授权见 docs/WORDMARK-FONT-LICENSE.txt。

参考图用于追溯设计；正式实现以 SVG 和色彩令牌为准。verification 包含轮廓与资产检查，不代表已测试你的软件。当前没有项目源码，软件接入由项目中的 Codex 完成。名称与图形尚未完成正式商标核查。
