# ELOVERIS 品牌与产品规范

## 1. 一条完整的品牌链

| 层级 | 定义 | 在软件中的落点 |
|---|---|---|
| ELOVERIS | 一个面向表达成长的独立品牌；名称作为整体使用，不编造词源或缩写 | 统一应用名称、关于页、启动界面与品牌素材 |
| 品牌哲学 | 让表达更清晰、更自在 | 给出可执行的反馈，让每一次练习都能继续向前 |
| 几何母题 | 宽阔的两岸，连续的留白，舒展的出口 | 稳定的卡片轮廓、清楚的内容间隔、连贯的练习路径 |
| Logo | 单色的蓝色两岸与透明河道共同组成一个完整标志 | 固定轮廓作为长期识别资产 |
| 色彩 | 蓝白识别，深蓝阅读，少量功能色 | 品牌色服务行动，功能色服务区分 |
| UI 动效 | 轻回应 → 顺畅衔接 → 完成停稳 | 操作有反馈，状态变化可理解，朗读过程安静 |

品牌承诺：帮助用户把想法逐步说清楚。希望来自“下一步可以做到”，力量来自稳定、清晰的系统回应。

产品可以从发音、朗读、口语练习延伸到对话、面试及多语言表达。品牌母题不绑定单一考试或某个模型。

## 2. 几何与 Logo

河道是一条开放、缓转的负形：上方进入，经过宽缓转弯，从右侧离开。两岸分别为独立闭合曲线，轮廓按认可参考图拟合并清理采样噪声。不要重新用字母 S、等宽波浪线或剪贴图拼成近似标志。

- 蓝色母版：eloveris-mark-blue.svg，viewBox 512 × 512，图形最大跨度约 432。
- 标志周围净空至少为可见图形高度的 1/4；SVG 自带边距不足时由容器补齐。
- 独立符号可见高度建议 ≥ 24 CSS px。低于 24 px 使用实底 app icon；16 px 与 20 px 均复用同一母版，不创造新形状。
- 组合字标建议宽度 ≥ 160 CSS px；空间不足使用符号。侧栏扩展显示组合字标，折叠显示符号。
- 白底使用蓝符号＋深蓝字标。深蓝或蓝底使用白色正形；河道透出背景。反白版不是单独画出一条白色河道。
- 应用图标采用蓝底与白色正形。使用给定 SVG/PNG/ICO，平台可按自身规范添加遮罩。
- 不改变长宽比、通道宽度或两个图形的位置。Logo 保持纯色；不添加玻璃、光泽、描边、发光或旋转。

字标统一大写 ELOVERIS；交付文件以 DejaVu Sans Regular 为基础转为路径，统一字高与间距。它是生产字标，不作为软件正文的字体依赖。正文沿用当前项目的系统字体或已授权字体；中文优先项目现有字体，其次系统无衬线。

正常文字与背景对比度目标 ≥ 4.5:1。边框令牌用于装饰；重要输入边界、控件轮廓及焦点使用更深的颜色。CSS 中提供 control-border。

保留产品已有分类色：节奏蓝 #2364EB、发音紫 #7C3AED、停顿橙 #B45309、表达粉 #BE185D。颜色与分类稳定绑定，并同时提供文字或图标。分类色不等于质量高低，状态成功色不替代所有分类色。

大面积以白与浅灰蓝为主，蓝用于身份和关键行动。自然风景图保留，用于情境与适度的情绪温度；文字阅读区保持稳定纯色背景。已有轻透光面板可以保留，Logo 本体始终实色。正文区不叠加河流纹理。

## 4. 版式与人文关怀

延续现有侧栏、主练习区与右侧反馈区。主阅读区优先保障句子、当前行动和反馈的层级。原有圆角、阴影与间距先映射到令牌，避免一次性改变全部布局。

参考值：4/8/12/16/24/32/48 px 间距；控件圆角 12 px，卡片 20 px，外壳 28 px。这些是目标尺度，应适配现有密度。正文 14–16 px，阅读练习 20–24 px，正文行高约 1.5–1.7；不要硬编码全局字体大小覆盖既有页面。

反馈描述具体动作：例如“这句可以稍微放慢，重音放在 actions 上”。表扬绑定实际表现，不把用户定义为某种能力水平。错误文案说明可恢复路径。

| 状态 | 建议文案 | 数据要求 |
|---|---|---|
| 就绪 | 开始练习 | 用户主动开始 |
| 录音 | 正在聆听 · 点击结束 | 来自真实录音状态；波形来自音频 |
| 分析 | 正在整理反馈 | 无进度接口时不显示虚构百分比 |
| 反馈 | 先练习这一处 | 绑定实际反馈建议 |
| 完成 | 这次练习已保存 | 确认保存成功后显示 |
| 失败 | 连接中断，录音已保留。重试分析 | 仅在确实保留录音时这样写，否则提供符合事实的恢复操作 |

品牌短句只用于欢迎、介绍与关于页。练习页采用直接、实用的语言。

## 5. 动效

| 行为 | 时长 | 方式 | 目的 |
|---|---|---|---|
| 悬停 / 按下 | 120 ms / 80 ms | 颜色过渡，按下轻微缩放至 .98 | 确认操作 |
| 菜单与反馈进入 | 180 ms | opacity + translateY 4 px → 0 | 呈现下一步 |
| 退出 | 120 ms | opacity | 清理视线 |
| 当前句切换 | 160 ms | 高亮底色切换 | 稳定阅读位置 |
| 成功反馈 | 220 ms | 成功标识淡入后停稳 | 完成闭环 |
| 真实分析中 | 1200 ms 循环 | 单一指示点轻呼吸 | 表示仍在工作 |

进入缓动 cubic-bezier(.2,.8,.2,1)；退出 cubic-bezier(.4,0,1,1)。避免弹簧回弹、卡片漂浮、Logo 流动、循环闪烁与朗读文字位移。反馈动画结束后保持静止。录音和分析的起止由真实状态驱动，不能由动画计时器模拟业务完成。

尊重 prefers-reduced-motion 和应用内“减少动态效果”。减少动态模式取消位移与循环动画，保留静态状态文本和焦点可见性。动效只增强理解，不能作为唯一提示。录音按钮与反馈面板需要可访问名称；分析文本可使用 aria-live="polite"，避免逐帧播报波形或数字。
