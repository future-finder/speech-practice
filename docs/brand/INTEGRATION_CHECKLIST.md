# 接入与验收

| 入口 | 资源 / 行为 |
|---|---|
| 侧栏展开、欢迎、关于 | eloveris-lockup-color.svg；深色表面用 white |
| 侧栏折叠、紧凑导航 | eloveris-mark-blue.svg；深色用 white |
| 桌面、任务栏、窗口 | app-icon PNG / Windows ICO；检查项目平台要求 |
| 网站页签（如有） | eloveris-favicon.svg 或 32 px PNG |
| 按钮、选中句、焦点 | 品牌语义令牌；焦点不只改变背景 |
| 录音 → 分析 → 反馈 | 真实状态驱动，匹配动效与文案 |
| 已保存、错误、空状态 | 验证实际结果；提供明确下一步 |

实施顺序：清点现有品牌资源和显示字符串 → 映射令牌 → 替换资产 → 接入状态动效 → 检查主题、辅助功能与平台构建。

- 清理对旧圆环、旧轨道及旧名称的展示引用；不要无差别替换第三方依赖或业务字段。
- 资源大小、路径与打包配置核对；SVG 无外部依赖，白版在深色背景检查。
- 若为 Electron，分别检查 BrowserWindow 图标与打包工具图标字段，ICO 仅适用 Windows；macOS 如需 ICNS 用本包 1024 PNG 按平台工具生成。
- 看 16/24/32/48 px 的实际尺寸，不只看放大图；小尺寸优先 app icon。
- 检查长名称、窄窗、侧栏折叠、高 DPI 和已有暗色主题。暗色页用白字标，品牌蓝不直接承担小号正文。
- 按钮有键盘焦点、状态同时有文字；必要文字达到 4.5:1 对比，重要非文字控件达到 3:1。
- 减少动态模式下仍能判断录音、分析、成功、失败；中断和重试不丢失已有数据。
- 启动、录音权限、录音结束、分析成功/失败、反馈和保存按项目已有流程验证。没有源码或接口的验证如实标记未执行。
- 记录显示品牌替换；列出技术标识、更新渠道与存储目录保留/迁移的理由。

包内检查：见 verification/asset-checks.json（形状、SVG与透明通道）、contrast-checks.json（令牌对比度）。这些只验证交付资产，不代替应用验收。
